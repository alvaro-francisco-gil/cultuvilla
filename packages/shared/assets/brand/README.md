# CULTUVILLA lettering

The wordmark. Use these files as-is rather than re-typesetting the word: the
letters are converted to outlines, so the SVGs render identically without the
font installed.

| File | Use |
|---|---|
| `cultuvilla-lettering.svg` | Transparent background — the master |
| `cultuvilla-lettering-cream.svg` | On the app cream, with margin |
| `cultuvilla-lettering.png` | 4000 px wide, transparent |
| `cultuvilla-lettering-cream.png` | 4000 px wide, on cream |

## Spec

- **Typeface:** Titan One (Rodrigo Fuenzalida), all caps. SIL Open Font License 1.1 —
  free for logo and commercial use.
- **CUL:** `#566047` (palette `olive`)
- **TU:** `#79845f` (a softer olive; not in the app palette)
- **VILLA:** `#bb5d3a` (palette `terracotta`)
- **Cream ground:** `#f9f0e8` (palette `cream`)
- **Kerning:** the L–T pair is tightened by −0.09em on top of the font's own
  kerning, so the T's crossbar slightly overlaps the L's foot (T drawn on top).
